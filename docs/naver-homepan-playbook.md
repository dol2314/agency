## 2. 제목 규칙 v4 — 가장 발전된 자산

블로그3 `CLAUDE.md` 0-2절. 11/20 제정, 11/21 글부터 적용.

### 제목은 두 종류

| 종류 | 목적 | 쓰는 법 |
|---|---|---|
| **홈판형** | 홈판에서 넘기다가 **멈추게** 하기 | 클릭 이유 1~2개를 골라 **제목 앞쪽**에 |
| **검색형** | TV·뉴스에서 본 상품을 **찾아오는** 사람 | **브랜드·상품·행사명으로 시작** + 숫자(가격) |

검색형 예: 「올리비아로렌 69만원 다운이 25만9천원.. 수험생 부모님 특가」

### 클릭 이유 7가지

| 클릭 이유 | 제목에 들어가는 말 |
|---|---|
| 손해 보기 싫다 | 29만→7만9천원 · 반값 · 아울렛 |
| 남들은 뭘 사나 | 하루 만에 품절 · 동났다 · 요즘 엄마들이 |
| 상류층 엿보기 | 재벌가 · 700만원 가방 |
| 동년배 | 50대 맞아? · 59세에도 |
| 수다 거리 | 호불호 갈린 · 반응 |
| 가족 | 남편 패딩 · 딸이 탐내는 · 수험생 부모 |
| 체형 고민 | 키 158cm · 뱃살 · 팔뚝 |

### 이름과 나이 — 습관으로 붙이지 않는다

- **이름**은 그 사람이 **클릭 이유일 때만**. 세 경우: 상류층(김희영) / 지금 화제(장나라 굿파트너2) / 5060 롤모델
- 그 밖에는 **「이 배우」·「한 여배우」로 가린다**
- **나이**는 '동년배'가 클릭 이유일 때만. 습관처럼 붙이던 **「45세 ○○○」는 폐지**

> 이 규칙은 v3 → v4로 진화한 것이다. v3 이전에는 이름+나이를 관성으로 붙였고, 운영자가 *"11/7에 쓴 제목도 45세 장나라로 시작하잖아"* 라고 직접 지적해 고쳤다.

### 공통 규칙

- **25~40자**
- 따옴표로 시작 금지, **이모지 금지**
- 품목 또는 브랜드를 **하나** 넣는다
- 궁금증 훅(이유·비결·정체·`?`·`..`) 또는 가격을 넣는다
- 하루에 클릭 이유가 **한쪽으로 몰리지 않게** 섞는다

## 3. 소재 배제 기준 — 세 블로그 공통

**근거를 못 찾으면 쓰지 않는다.** 이게 가장 중요한 원칙이고 자동 루틴에 박혀 있다.

실제로 뺀 사례:

| 뺀 소재 | 이유 |
|---|---|
| 잠실래미안아이파크 재공급 | 청약일·분양가 미공개, 청약홈 공고 없음 |
| 강동한강디에트르 | 청약일·분양가 기사 못 찾음 |
| 연말 폐장일·배당락일 | 거래소 미발표 |
| 김명민 유퀴즈 | 다음 주 방송 예고뿐 |
| 강균성 동상이몽2 | 아직 방송 전 |
| 정웅인 4인용식탁 | 구타 논란으로 반응 엇갈림 |
| 성유리 남편 | 재판 소식 |
| 22기 옥순 | 일반인 출연자 |

| 「T&C 다음은 S KHY」 이니셜 논란 | 쓰지 않기로 판단 |

**유형으로 정리하면:**
- ❌ 공식 발표·공고가 없는 숫자 (가격·일정)
- ❌ 아직 방송 전 / 예고만 있는 것
- ❌ 사건·사생활·논란·재판
- ❌ 젠더 소재
- ❌ 일반인 출연자

### 사실 확인 기준

- **기사 2~6곳에서 교차 확인**
- 한 곳에만 나온 내용은 본문에 **"○○ 보도에 따르면"** 으로 출처를 밝힌다
  (예: 이유리 그네 청혼 → MK스포츠 / 최태성 김지섭 일화 → 뉴스엔)

## 4. 사진 — "썸네일이 제일 중요하다"

운영자 본인의 판단: **"썸네일 사진이 제일 중요해, 후킹 쌘걸로"**

### 대표사진 고르는 기준 (블로그3)

- **글자 없는 당사자 사진**
- **옷이 잘 보이는 컷**
- 후보를 **정사각으로 잘라 놓고 비교**해서 고른다 (`thumb_pick.py`)

### 사진 출처 규칙

- ✅ 방송 화면 캡처, 방송사 제공 사진
- ❌ **신문사 사진 금지**
- 화면 안에 **보도사진이 들어간 컷은 제외** (예: 고우림 글에서 이상화·김연아 선수 시절 보도사진이 들어간 컷을 뺐다)

### 🔔 실전 함정: 대표사진이 화면 표시와 다르다

> 발행 직전 화면에서는 **'대표' 표시가 맨 끝 사진**에 붙어 있었는데, 실제로 발행된 글의 대표 이미지는 **첫 사진(`0_썸네일`)** 이었다.

**첫 사진을 대표로 쓰고 싶은 컷으로 배치해야 한다.** 화면의 '대표' 표시를 믿지 말 것.

## 5. 운영 함정 — 실전에서 발견된 것

| 함정 | 조치 |
|---|---|
| **크리에이터샵 카드 가운데 정렬 실패** — 4개 중 1개가 자주 안 됨 (김나영·문가영·김희영·장나라 글에서 같은 패턴) | 예약 상태에서 다시 열어 수정. 발행 엔진에 "첫 시도에서 안 바뀐 카드는 성공했던 위치를 눌러 한 번 더 시도" 로직 추가 |
| **임시저장 사본이 남는다** — 예약 목록엔 0건인데 발행 직전 화면에 '저장 1' | 임시저장함을 직접 확인해 삭제 (사용자 작업) |
| **같은 인물 재등장 시 겹침** | 이전 글에 **없던 사진**을 쓰고, 본문 각도를 다르게 (장나라 11/7 글 → 11/21 글은 첫방 성적·김혜윤 합류·1회 의상 중심으로 전환) |
| 본문 글자수 미달 | 확인된 사실로 한두 문장 보태고 재검사 |

### 발행 전 자동 검사 항목

빠진 문단 · 순서 오류 · 서식 어긋남 · **백링크 주소 글자** · 태그 중복 · 예약 시각(hour/minute) — **전부 0이어야 통과**

블로그3은 `build_post.py` 에서 원고 생성 시 자동 검사. **클릭 이유가 제목에 안 보이거나, 이유 없이 이름·나이가 들어가면 걸린다.**

전체 운영이 홈판 노출을 목표로 돌아가는데, **홈판 노출 자체를 측정한 흔적이 없습니다.** 지금 쌓이는 것은 조회수이고, 조회수는 홈판 노출의 **결과**이지 홈판 노출 **여부**가 아닙니다.

→ 글마다 `홈판 노출 Y/N`과 (떴다면) `어느 주제판·언제`를 기록해야 `title_report.py` 가 "어떤 제목이 홈판에 뜨는가"를 답할 수 있습니다. 지금은 "어떤 제목이 조회수가 높은가"까지만 답합니다.

### 블로그 간 A/B — 지금 할 수 있습니다

블로그가 3개고 포맷이 서로 다르니 거의 통제된 실험이 가능합니다. 1절의 **인용구 1개 vs 9개** 모순부터:

