# kr-brand

브랜드는 고객이 기억하는 약속이다. 예쁜 색 모음이 아니라 **포지셔닝에 맞는 구체적인 것**을 만든다.

> 원작: [founder-brand](https://github.com/Jakeschincariol/founder-skill) (MIT, Jake Schincariol). 한국 상표·상호·도메인 제도와 한글 폰트 라이선스에 맞춰 고쳤다.

---

## 0단계: 무엇의 이름인가

| 대상 | 필요한 확인 수준 |
|---|---|
| **사업체** (법인·개인사업자) | 상표 + 상호 + 도메인 + 핸들 — 전부 |
| **웹사이트·서비스** | 상표 + 도메인 + 핸들 |
| **블로그·유튜브 채널** | 핸들 중복 + **검색 가능성** (상표는 보통 과함) |
| **비영리·기관 사업명** | 유사 기관명 중복 + 지자체 공고상 명칭 규칙 |

사업체 이름과 서비스 이름이 다를 수 있다. **어느 쪽인지 먼저 확인한다.**

---

## 1단계: 브리프 읽기

있으면 읽는다. **없으면 사용자에게 포지셔닝을 한 줄로 물어보고 진행한다** (원작과 달리 다른 스킬 출력을 요구하지 않는다):

- `marketing/plan.md` — 포지셔닝 한 줄, 첫 번째 고객층
- `research/competitors.md` — 피해야 할 이름·느낌
- 없으면: "누구에게, 무엇을, 무엇과 다르게" 세 가지만 받는다

---

## 2단계: 이름 후보

**한글·영문을 같이** 만든다. 국내는 한글 이름으로 검색되고 영문은 도메인·핸들에 쓰인다.

후보 10개를 서로 다른 결로:

| 결 | 예 |
|---|---|
| 설명형 | 복지카드 안내소 |
| 연상형 | 댕댕맵 |
| 조어형 | 플리토 |
| 사람·지명형 | 정다운, 김포 |

각 후보마다 적는다:
- 무엇을 말하는가
- **소리 내어 읽었을 때** — 받침 충돌, 발음 어려움, 줄여 부르면 어떻게 되나
- 간판·앱 아이콘(32px)·유튜브 썸네일에서 어떻게 보이나
- **로마자 표기** — 국어의 로마자 표기법 기준, 그리고 사람들이 실제로 쓸 표기 (예: 정다운 → `jeongdaun` / `jungdaun` 둘 다 선점 검토)
- 위험

### ⚠️ 한국에서 가장 흔한 실수 — 검색 가능성

**이름이 일반명사면 검색으로 못 찾는다.** 네이버에서 브랜드명을 검색했을 때 다른 것들과 섞여 묻히면, 그 이름은 마케팅 비용을 영구적으로 더 쓰게 만든다.

후보 3개를 **네이버와 구글에서 각각 그대로 검색**해서 적는다:
- 1페이지에 무엇이 나오나
- 동명의 다른 사업체·연예인·지명·일반명사가 있나
- **"브랜드명 + 업종"** 으로 검색했을 때는 찾아지나

예: `정다운` 단독 검색은 동명인이 많다 → `정다운장애인자립생활센터` 처럼 업종을 붙인 전체 명칭이 실제 검색 단위가 된다.

---

## 3단계: 확인 목록 — 사용자가 직접 끝내야 하는 것

후보 3개를 추린 뒤 아래를 준다. **내가 대신 등록하거나 확정할 수 없다.**

| 확인 | 어디서 | 무엇을 |
|---|---|---|
| **상표** | 키프리스 <http://www.kipris.or.kr> | 같은·유사 상표를 **같은 상품분류(NICE)** 에서. 분류 번호를 지정해 준다 |
| 상표 출원 | 특허로 <https://www.patent.go.kr> | 출원은 사용자가. 등록까지 보통 1년 이상 |
| **상호** | 인터넷등기소 <http://www.iros.go.kr> | 법인이면 같은 관할구역 동일·유사 상호 |
| 사업자등록 | 홈택스 | 개인사업자 상호는 중복 가능하지만 상표권과 별개 |
| **도메인 .kr/.co.kr** | <https://whois.kr> | 등록 여부. `.com`도 같이 |
| **네이버 블로그 ID** | 블로그 만들기 화면 | 선점 여부 (한 번 정하면 변경 불가) |
| **유튜브 핸들** | 채널 설정 | `@핸들` 중복 |
| 인스타·틱톡·X | 각 가입 화면 | — |
| **카카오톡 채널 검색용 ID** | 카카오 비즈니스 | 중복 |
| **혼동 위험** | `research/competitors.md` | 경쟁자와 비슷한 이름 금지 |

**반드시 이렇게 말한다**: 나는 공개 검색만 할 수 있다. 상표 가능성의 최종 판단은 **변리사**가 한다. 그리고 **사용자가 등록하기 전까지는 아무것도 확보되지 않았다.** 이름을 확정하고 간판·명함을 만들기 전에 키프리스 확인부터 끝내야 한다.

---

## 4단계: 약속과 말투

- **약속 한 줄** — 고객이 매번 기대할 수 있는 것
- **슬로건 3개**
- **말투를 형용사 3개**로, 각각 `이렇게 쓴다` / `이렇게 쓰지 않는다` 한 쌍씩
- 실제 문장 하나를 **고치기 전/후**로 보여준다

한국어 특유로 결정할 것:
- **높임 수준**: `~합니다` / `~해요` / `~한다`. 섞이면 아마추어로 보인다. **하나로 고정한다**
- 고객을 뭐라고 부르나: `고객님` / `회원님` / `보호자님` / 호칭 없이
- **어르신·장애인이 주 독자면**: 짧은 문장, 한 문장 한 뜻, 한자어보다 쉬운 말, 외래어 최소화

---

## 5단계: 디자인 브리프

### 색

핵심 색 2~3개를 **hex와 역할**로. 그리고 **명도 대비를 반드시 계산해 적는다**:
- 본문 텍스트: **WCAG AA 4.5:1 이상**
- 큰 글자(18pt 이상 또는 14pt 굵게): 3:1 이상
- **어르신·장애인 대상이면 AA로 그치지 말고 7:1(AAA)을 목표로 한다**
- 색만으로 정보를 구분하지 않는다 (색각 이상)

### 한글 폰트 — 라이선스를 반드시 확인한다

**무료라고 알려진 폰트도 용도별로 제한이 다르다.** <https://noonnu.cc> 에서 각 폰트의 **상업적 이용 / 임베딩 / BI·CI 사용 / 수정** 허용 범위를 확인하고, 확인한 내용을 브리프에 적는다.

- 비교적 안전한 선택: **Pretendard**, **본고딕/Noto Sans KR**, **나눔 계열** (각각 라이선스 재확인 필수)
- **BI·로고에 쓰려면 별도 허용이 필요한 폰트가 많다.** 로고용은 특히 확인한다
- 산돌·윤디자인 등 상업 폰트는 유료 라이선스 없이 쓰지 않는다
- **웹폰트로 쓸 때 임베딩 허용 여부는 별개 조항이다**

본문용 1 + 제목용 1을 고르고, 받을 곳과 **확인한 라이선스 조항**을 같이 적는다.

### 로고 브리프

- 무엇을 말해야 하나
- 어디서 작동해야 하나 (간판, 명함, 32px 파비콘, 유튜브 프로필 원형, 흑백 팩스)
- 피할 것
- 이미지 도구로 시안을 만들 수 있으면 제안하되, **"시안"이라고 명시한다.** 완성 로고가 아니다

### 첫 다섯 접점

간판 또는 홈 첫 화면 / 포장 또는 첫 이메일 / 영수증 또는 접수 확인 / 첫 게시물 / **첫 불만에 대한 답장**

콘텐츠 사업이면: 채널 아트, 썸네일 틀(글자 크기·위치 고정), 블로그 대표 이미지, 고정 인트로 문구, 첫 댓글 응대.

---

## 규칙

- 경쟁자의 이름·로고·색·슬로건을 **베끼지 않는다**
- 권리 없는 폰트·이미지·아이콘을 쓰지 않는다
- **공공기관으로 오인될 이름·로고·표현 금지** (정부 로고, "공식", `.go.kr` 유사 표기)
- 상표에 대한 **법률 자문이 아니다**
- 확인 못 한 중복은 "확인 못 함"으로 적는다. 비어 있게 두지 않는다
