# kr-youtube-growth

유튜브는 "올리면 누가 본다"가 아니다. **노출 → 클릭 → 지속**이라는 세 관문이 있고, 어디서 새는지는 스튜디오 숫자가 알려준다. 이 스킬은 추측 대신 그 숫자에서 시작한다.

> 수익 계산과 수익창출 관문 역산은 `kr-marketing` 0단계 ②가 담당한다. 여기서 중복하지 않는다.

---

## 절대 규칙 — 속설을 근거로 쓰지 않는다

유튜브 추천 알고리즘의 **가중치는 공개되지 않았다.** 다음은 공개된 근거가 없다. **이것들을 근거로 작업을 제안하지 마라:**

- "영상 길이는 N분이 최적이다"
- "업로드 시간대·요일이 노출을 결정한다"
- "태그가 검색 순위를 올린다"
- "초반 1시간 조회수가 영상의 운명을 정한다"
- "구독·좋아요 유도 멘트가 알고리즘 점수를 올린다"
- "특정 키워드를 설명란에 N번 넣어야 한다"

이런 요청을 받으면 **거절하지 말고, 근거가 없다고 말하고 측정 가능한 대안을 제시하라.**

**근거로 쓸 수 있는 것은 유튜브 스튜디오에서 측정되는 값과 유튜브 공식 문서뿐이다.** 기준일이 6개월 넘은 내용은 공식 고객센터에서 다시 확인하라.

---

## 1단계: 실측값을 받는다 — 이것 없이는 아무 진단도 하지 않는다

사용자에게 요청한다 (유튜브 스튜디오 → 분석):

| 항목 | 어디서 | 왜 |
|---|---|---|
| **노출수 · 노출 클릭률** | 분석 → 도달범위 | 썸네일·제목 문제인지 판정 |
| **평균 시청 지속 시간 · 평균 조회율** | 분석 → 참여도 | 내용 문제인지 판정 |
| **시청자 유지 그래프** (영상별) | 영상 → 분석 → 참여도 | **어디서** 떠나는지 |
| **트래픽 소스 유형** | 분석 → 도달범위 | 전략이 완전히 갈린다 |
| 구독자 증감 (영상별) | 분석 → 잠재고객 | 어느 영상이 구독을 만드나 |
| 롱폼 / Shorts 분리 수치 | 분석에서 필터 | 섞으면 판단이 망가진다 |
| 수익창출 상태 · RPM | 분석 → 수익 | 관문 전후 목표가 다르다 |

**최근 10~20편의 영상별 표**로 받는 것이 가장 좋다. 채널 평균 하나로는 진단이 안 된다.

없으면 "확인 못 함"으로 적고, 그 때문에 무엇이 추정인지 밝힌다. **채널 주소만 보고 진단하지 않는다.**

## 2단계: 어디서 새는지 판정한다

```
노출수  →  (노출 클릭률)  →  조회수  →  (평균 조회율)  →  시청시간
```

| 증상 | 어디가 문제 | 고칠 것 |
|---|---|---|
| 노출수 자체가 적다 | 유튜브가 추천을 안 한다 | 주제·시리즈 일관성, 검색 수요 있는 주제로 |
| 노출은 많은데 **클릭률이 낮다** | 썸네일·제목 | 3단계 |
| 클릭률은 좋은데 **조회율이 낮다** | 도입부·내용 | 4단계 |
| 클릭률 높고 조회율 낮음이 **같이** | **낚시 썸네일** | 3단계 끝 경고 참고 |
| 조회수는 나오는데 구독이 안 늘다 | 채널 정체성 | 5단계 |

**자기 채널의 과거 중위값과 비교한다.** "업계 평균 몇 %"는 주제·형식·국가마다 달라서 기준으로 쓰지 않는다. 비교 기준은 **내 채널의 지난 20편**이다.

---

## 3단계: 썸네일과 제목 (노출 클릭률)

### 썸네일 — 한국어 특수사항

- **글자는 최소로.** 모바일 피드에서 썸네일은 아주 작게 보인다. 한글은 영문보다 획이 많아 더 빨리 뭉개진다. **4~6글자**를 넘기면 읽히지 않는다고 보고 시작하라
- **고대비**: 어두운 배경 + 밝은 글자, 또는 반대. 테두리(스트로크)로 배경과 분리
- **얼굴·표정**이 들어가면 시선을 끈다는 것은 널리 쓰이는 방식이지만, 주제에 따라 역효과다. 내 채널 데이터로 확인하라
- **같은 시리즈는 같은 틀**을 쓴다 (위치·색·폰트 고정). 피드에서 "그 채널 영상"으로 알아보게 만든다
- 축소해서 확인한다: 실제 크기(모바일 피드 크기)로 줄여 보고 읽히는지 본다

### 제목

- **모바일에서 잘린다.** 앞부분에 핵심을 둔다
- 검색 유입을 노리면 사람들이 실제로 치는 말을 쓴다 (유튜브 검색창 자동완성으로 확인)
- 제목과 썸네일이 **같은 말을 반복하지 않게** 한다. 둘이 합쳐 하나의 메시지가 되게

### A/B 테스트 — 정직하게

- 유튜브에 **썸네일 테스트·비교 기능**이 있으면 그것을 쓴다 (채널에 따라 제공 여부가 다르다. 스튜디오에서 확인하라)
- 그 기능이 없으면: 썸네일을 교체한 **전후 비교는 엄밀한 A/B가 아니다.** 노출 맥락·시점·추천 상태가 달라졌기 때문이다. **"참고치"라고 명시하고 결론을 과신하지 마라**
- 교체 후 판단은 최소 며칠, 노출수가 충분히 쌓인 뒤에 한다

### ⚠️ 낚시 썸네일 경고

클릭률만 올리는 썸네일은 **역효과다.** 클릭률이 올라가도 조회율이 떨어지면 유튜브가 그 영상을 덜 추천한다. **두 지표를 항상 같이 본다.** 한쪽만 보고 좋아진 척 보고하지 마라.

## 4단계: 시청 지속 (평균 조회율)

### 유지 그래프 읽는 법

| 그래프 모양 | 뜻 | 고칠 것 |
|---|---|---|
| **첫 15~30초 급락** | 도입부가 기대와 다르다 | 인사·인트로·채널로고 제거. **첫 문장에 바로 본론** |
| 중간 특정 지점 급락 | 그 구간이 지루하거나 샜다 | 그 구간을 잘라내거나 압축 |
| 완만한 하강 | 정상 | 길이를 줄여 평균 조회율을 올릴 수 있다 |
| **중간에 상승 구간** | 되돌려 본 곳 = 사람들이 원한 내용 | 그 주제로 영상을 하나 더 |
| 끝까지 평평 | 매우 좋다 | 같은 형식을 유지 |

### 구체적으로 고칠 것

- **인트로 애니메이션·BGM 인사 삭제.** 첫 5초에 "이 영상에서 무엇을 얻나"를 말한다
- 제목이 약속한 것을 **미루지 않는다.** "마지막에 알려드립니다"는 이탈을 만든다
- **챕터(타임스탬프)** 를 넣는다 — 원하는 구간으로 가게 해서 이탈 대신 이동이 되게
- 긴 영상에서 조회율이 낮으면 **길이를 줄이는 것이 가장 빠른 개선**이다. 단, 시청시간 총량과의 트레이드오프를 계산해 보여준다:
  ```
  영상당 시청시간 = 길이 × 평균 조회율
  ```
  길이를 줄여 조회율이 오르더라도 **곱이 줄면 수익창출 관문에는 불리하다.** 관문 전이면 이 계산을 반드시 한다

## 5단계: Shorts와 롱폼 — 역할을 분리한다

| | Shorts | 롱폼 |
|---|---|---|
| 역할 | **발견·구독 유입** | **수익·시청시간** |
| RPM | 낮다 | 높다 |
| 관문 기여 | Shorts 조회 기준으로 별도 산정 | 시청시간 기준 |
| 지표 | 조회수, 끝까지 본 비율 | 평균 조회율, 노출 클릭률 |

- **Shorts 구독자가 롱폼을 보지 않는 일이 흔하다.** Shorts로 구독이 늘어도 롱폼 조회수가 안 오르면 그 사실을 그대로 보고한다
- 관문 전이라면 **어느 경로가 더 싼지** 계산한다 (`kr-marketing` 0단계 ②의 두 조건을 각각 역산)
- Shorts를 롱폼의 예고로 쓸 때는 **같은 내용을 잘라 붙이지 말고** 궁금증만 만든다

---

## 6단계: 시리즈·재생목록·채널 구조

- **재생목록**은 연속 재생으로 세션 시청시간을 늘린다. 관문 전에 특히 효과가 있다
- **시리즈로 묶는다.** 단발 영상 10개보다 한 시리즈 10편이 추천을 받기 쉽다 (같은 시청자가 다음 편을 보기 때문)
- **최종화면·카드**로 다음 영상을 지정한다. 아무 영상이 아니라 **방금 본 영상과 이어지는 것**으로
- 채널 홈: 신규 방문자용 섹션(대표 영상)과 구독자용 섹션을 나눈다
- **자막**: 한국어 자동 생성 자막은 오류가 많다. 중요한 영상은 직접 수정한다 (검색·접근성 양쪽에 도움)

---

## 7단계: 발행 주기

- **지킬 수 있는 주기**를 정한다. 주 3편을 2주 하고 멈추는 것보다 주 1편을 1년 하는 것이 낫다
- 주기를 바꾸면 **최소 8주는 유지**하고 비교한다. 2~3편으로 판단하지 않는다
- 업로드 시간대 최적화는 **근거가 공개되지 않았다.** 신경 쓸 순위가 아니다

---

## 지표와 판정 기준선

주간으로 보는 것 (내 채널 과거 중위값과 비교):

| 지표 | 뭘 말해주나 | 뭔가 바꿔야 하는 신호 |
|---|---|---|
| **노출 클릭률** | 썸네일·제목 | 과거 중위값 아래로 3편 연속 |
| **평균 조회율** | 도입부·내용 | 과거 중위값 아래로 3편 연속 |
| 노출수 | 유튜브의 추천 의지 | 영상 수는 유지인데 감소 추세 |
| 영상당 구독 전환 | 채널 정체성 | 조회는 늘고 구독은 평평 |
| (관문 전) 누적 시청시간·구독자 | 관문까지 거리 | 역산 속도보다 느림 |

**3편 연속**을 기준으로 둔 이유: 영상 1~2편의 변동은 노이즈다. 한 편 보고 전략을 바꾸지 마라.

## 하지 말 것

- **조회수·구독자·좋아요 구매** — 정책 위반이고 채널이 날아간다
- 낚시 썸네일·제목 (3단계 경고)
- **저작권 없는 음원·영상·이미지** 사용
- 다른 채널 영상 재업로드, 자동 생성·반복 콘텐츠 (재사용 콘텐츠 정책 위반)
- **대가성 표시 누락** — 협찬·제공받은 제품이 있으면 유튜브의 유료 프로모션 표시 기능을 켜고 **본문·영상 안에서도 밝힌다** (공정위 심사지침 대상. 상세는 `/kr-blog-income` 4단계)
- 의료·건강기능식품 효능 주장
- 미성년자가 등장하는 콘텐츠의 아동용 설정 오기재

## 산출물

`youtube/growth.md`:

1. 최근 10~20편 실측 표 (노출수·클릭률·조회율·구독증감) — **받은 값만**
2. 2단계 판정: 어디서 새고 있나
3. 그 지점에 대한 구체적 수정안 (썸네일 시안 방향 / 잘라낼 구간 / 도입부 다시 쓰기)
4. Shorts·롱폼 역할 배분과 관문까지 역산 (관문 전인 경우)
5. 재생목록·시리즈 구조 제안
6. 주간 지표 3개와 기준선
7. 확인 못 한 항목 목록
