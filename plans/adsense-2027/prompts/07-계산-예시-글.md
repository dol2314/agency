# 프롬프트 07 — 계산 예시 글 (주 3편, 반복 실행)

## 목표
계산기마다 "실제 상황 하나를 끝까지 계산해 보는 글"을 붙여 검색 유입과 방문당 페이지뷰를 늘린다. AI가 한 문단으로 대신할 수 없는 글이어야 한다.

## 이 프롬프트는 매주 실행한다. 한 번에 3편까지만.

## Claude Code에게
```
docs/plan/README.md 3-4절과 docs/keywords/priority.md(있으면)를 읽어라.
이번 주 주제(운영자가 지정, 없으면 priority.md 상위에서 아직 글이 없는 것 3개를 제안하고 승인받은 뒤 진행): {{이번 주 주제 3개}}

각 글의 형식:
1. 제목: 상황 + 숫자 + 연도. 예) "혼자 사는 72세, 월 소득 120만 원이면 2027 기초연금 얼마?"
2. 첫 3문장: 결론(금액·가능성), 기준일, 계산기 링크
3. 상황 설정 표(가구원, 나이, 소득, 재산 — 가상의 예시임을 명시)
4. 단계별 계산: lib/calc 엔진을 실제로 실행한 값만 쓴다. 단계마다 어떤 기준이 적용됐는지 한 줄
5. "이 상황에서 자주 놓치는 것" 3가지 (운영자 현장 메모가 있으면 그것을 우선)
6. 조건이 조금 바뀌면? (소득 +10만 원, 가구원 +1 등 2~3개 변형 → 엔진 계산값)
7. 신청 방법·준비물·문의처 (공식 링크)
8. FAQ 3개, 관련 계산기·글 링크 3개
9. 출처·기준일·검수일·작성자

품질 검사 (글마다 실행하고 결과 첨부):
- 기존 글과 문장 유사도: 3-gram 겹침 30% 이상인 문단이 있으면 고쳐 쓴다 (scripts/check-similarity.mjs 를 처음 실행 때 만든다)
- 본문 숫자가 모두 엔진 계산값 또는 data JSON 값과 일치하는지 검사
- 1,500자 미만이거나 예시 변형이 2개 미만이면 공개하지 않는다

글은 draft 상태(사이트맵 제외, noindex)로 커밋하고, 운영자가 검수 후 publish 플래그를 켜도록 하라. 운영자 검수 체크리스트를 보고에 붙여라.
```

## 운영자 작업

- 검수 후 publish → 서치어드바이저 수집 요청
