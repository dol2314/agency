# 프롬프트 06 — 광고 배치 + 애드센스 정책 점검

## 목표
같은 방문자로 더 벌되, 정책 위반·이탈 증가 없이. 클러스터 A·B 공개 직후 실행.

## Claude Code에게
```
docs/plan/README.md 4-3절(광고 배치)과 CLAUDE.md 규칙 5를 읽어라.

1. 현재 광고 코드(adsbygoogle 스크립트, ins 태그, 자동 광고 설정)를 전부 찾아 페이지 유형별 표로 정리하라.
2. 재사용 컴포넌트 <AdSlot position="after-result|in-content|end" /> 를 만든다:
   - 레이아웃 이동(CLS)을 막기 위해 최소 높이 예약
   - 화면에 들어올 때 로드(지연 로딩)
   - 주변에 "광고" 라벨, 버튼·링크와 최소 간격 확보
   - 개발 환경에서는 회색 자리표시자만 표시(실제 광고 요청 금지)
3. 4-3절 표대로 계산기 페이지·글 페이지에 배치한다. 계산기 첫 화면(모바일 360×640 기준)에 광고가 입력 폼보다 먼저 보이면 안 된다.
4. 정책 점검 스크립트 scripts/check-ad-policy.mjs: 빌드 HTML에서 (a) "클릭" "눌러" 등 유도 문구가 광고 주변 200자 안에 있는지, (b) 한 페이지 광고 수, (c) 첫 화면 광고 여부(Playwright로 모바일 뷰포트 스크린샷 + 요소 위치)를 검사한다. Playwright는 설치된 것을 쓴다.
5. history.pushState/popstate 로 뒤로 가기를 조작하는 코드가 없는지 검사하라.
6. 개인정보처리방침에 애드센스(쿠키·광고 ID)·GA4 고지가 있는지 확인, 없으면 초안을 만들고 운영자 검토 요청.
7. 결과 보고: 페이지 유형별 광고 수, 스크린샷 경로, 위반 의심 목록.
```

## 운영자 작업
- 애드센스 콘솔: 자동 광고는 "페이지 내 광고"만 켜고, 앵커·비네트는 2주 A/B 후 결정
- 애드센스 승인 전이라면: 빈 카테고리·자리표시 페이지가 없는지 확인 후 신청 (승인 전에는 광고 코드는 자동 광고 스니펫 하나만)
