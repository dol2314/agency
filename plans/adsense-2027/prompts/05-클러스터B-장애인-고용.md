# 프롬프트 05 — 클러스터 B: 장애인 고용 섹션 (/work/)

## 목표
기업 인사담당자와 장애인 근로자가 찾는 계산기를 새 섹션으로 만든다. 고용부담금 신고 시즌(1월) 전, 12월 15일까지 공개 목표. 광고 단가가 가장 높고 경쟁이 적은 칸이다.

## 전제
- 03 완료. 01에서 클러스터 B 검색량이 확인됐으면 그 결과로 페이지 범위를 조정한다(합계가 매우 작으면 운영자와 상의 후 실업급여만 진행).

## Claude Code에게
```
docs/plan/README.md 3-3절(클러스터 B), 3-4절, 4-1절을 읽어라.

공식 자료 확인이 이 작업의 절반이다. 아래 값을 한국장애인고용공단·고용노동부·법제처(장애인고용촉진 및 직업재활법, 시행령, 고시)·고용24에서 찾아 lib/calc/data/2027.json(없으면 2026)의 work 섹션에 출처와 함께 넣어라:
- 의무고용률(민간·공공), 의무고용 대상 사업주 기준(상시근로자 수), 부담금 납부 대상 기준
- 부담기초액(고용 수준 구간별 가산 포함), 장애인을 한 명도 고용하지 않은 경우 적용액
- 고용장려금 지급 단가(성별·중증 여부별), 지급 기준
- 신고·납부 기한과 신청 경로
- 실업급여: 상한액, 하한액 산식(최저임금 연동), 소정급여일수 표(나이·피보험기간, 장애인 구분 포함)
찾은 값마다 source_url과 effective_date. 못 찾은 값은 verified:false 로 두고 해당 계산기는 공개하지 않는다.

만들 페이지:
1. /work/ 허브: 회사용(의무고용·부담금·장려금)과 근로자용(실업급여·근로지원) 두 갈래
2. /work/quota/ 의무고용 인원 계산기: 월별 상시근로자 수 → 의무 인원(소수점 처리 규칙은 법령대로), 현재 장애인 근로자 수 입력 → 미달/초과 인원
3. /work/levy/ 고용부담금 계산기: 월별 입력(12개월) 또는 연평균 간편 입력, 중증 장애인 2배수 인정 규칙 반영(법령 확인), 결과에 "신고 기한·납부 방법·공식 신고 경로" 링크
4. /work/incentive/ 고용장려금 계산기: 초과 고용 인원 × 단가, 지급 제외 기준 안내
5. /calc/unemployment-benefit/ 실업급여 계산기: 이직 전 3개월 임금 → 1일 구직급여액(상·하한 적용), 소정급여일수, 총액. 장애인 근로자 예시 포함.
6. 각 계산기는 3-4절 8개 항목 충족. 계산 예시는 회사 규모별(상시 60명 / 150명 / 400명) 등 실제 엔진 계산값으로.
7. 기업용 페이지는 문체를 "회사 인사담당자에게 말하듯" 바꾸되, 법률 자문이 아님을 명시하고 공단 상담 연결 링크를 둔다.
8. lib/calc/__tests__ 에 각 계산기 최소 5케이스(공단·법령 예시 기준), 경계값 포함.
9. 홈 상황별 바로가기에 "회사 인사담당자" 추가. 사이트맵 추가(20개 이하).
10. 빌드·테스트·품질 검사 스크립트 결과와 verified:false 목록을 보고하라.
```
