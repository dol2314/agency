# 프롬프트 02 — 기술 기반 정비 (감사 P0)

## 목표
기존 기술 감사에서 나온 P0 문제를 먼저 고쳐, 이후 새로 만드는 페이지가 제대로 색인·공유되게 한다.

## 먼저 읽을 것
- `docs/plan/audit-brief.md` (시작 프롬프트에서 복사됨. 원본: `dol2314/agency` 브랜치 `claude/hopeful-goldberg-xuk9k3`의 `audits/briefs/bokjicard.md`, 작업 T1~T7)

## Claude Code에게
```
docs/plan/audit-brief.md 의 작업 T1~T7을 순서대로 처리하라. 각 작업의 "완료 조건"을 실제 명령(curl -sI, 빌드 후 HTML 확인)으로 검증하고 결과를 붙여라.

추가로 아래를 확인·처리하라:
1. app/ 아래 모든 페이지의 metadata에 canonical·og:image·og:url이 각 페이지 고유값으로 들어가는지 스크립트로 검사(빌드 결과 HTML을 파싱). 누락 목록을 고친다.
2. public/ads.txt 내용이 애드센스 퍼블리셔 ID 한 줄로 정확한지 확인(값은 운영자에게 확인받은 것만).
3. robots.txt: 학습용 크롤러(GPTBot, Google-Extended, CCBot 등)를 막을지는 운영자 결정 사항이다. 지금 상태를 보고하고, 사용자 대리 에이전트(ChatGPT-User, Claude-User, Perplexity-User)는 막지 말 것을 권고로 적어라. 직접 바꾸지 마라.
4. IndexNow: 빌드 후 변경된 URL을 POST하는 scripts/indexnow.mjs 와 키 파일을 만든다(키 값은 운영자가 생성해 환경변수로 넣도록 안내).
5. about 페이지에 운영자 실명·경력·연락처·검수 원칙이 있는지 확인. 없으면 자리만 만들고 운영자에게 내용을 요청하라(내용을 지어내지 마라).

Cloudflare 설정이 필요한 항목(T1, T2 등)은 직접 할 수 없으니 운영자가 따라 할 단계를 정확히 적어라.
```

## 운영자 작업
- Cloudflare: Always Use HTTPS, 슬래시 리다이렉트 규칙 (브리프의 규칙 그대로)
- 서치콘솔(도메인 속성)·네이버 서치어드바이저·Bing 웹마스터 등록, 사이트맵·RSS 제출

## 완료 조건
- `curl -sI http://bokjicard.co.kr/` → 301 → https
- 모든 공개 페이지의 canonical·og:image가 고유값 (검사 스크립트 출력 첨부)
- `scripts/indexnow.mjs` 동작 (드라이런 출력 첨부)
