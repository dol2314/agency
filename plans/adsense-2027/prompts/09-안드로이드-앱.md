# 프롬프트 09 — 안드로이드 앱 "복지 알림"(가칭) MVP

## 목표
기기 안에 내 조건을 저장해 두면, 받을 수 있는 복지를 보여 주고 신청 기간을 먼저 알려 주는 앱. 웹과 같은 계산 엔진을 쓴다. AdMob으로 수익화.

## 전제
- 03(lib/calc 엔진), 08(calendar JSON) 완료
- 운영자: Google Play 개발자 계정, AdMob 계정·앱 등록(앱 ID, 광고 단위 ID) 준비

## Claude Code에게
```
docs/plan/README.md 5장을 읽어라.

구조 결정: 저장소 안에 apps/android-app/ (또는 운영자가 정한 위치)로 만든다. lib/calc 를 앱이 import 할 수 있게 패키지 경계를 정리하라(예: npm workspaces, 또는 tsconfig paths). 웹 빌드가 깨지지 않아야 한다.

1. 스택: Vite + React + TypeScript + Capacitor(Android). 플러그인: @capacitor/local-notifications, @capacitor/preferences(기기 저장), @capacitor/app, @capacitor-community/admob. 각 패키지는 현재 안정 버전을 확인해 고정 버전으로 설치.
2. 화면:
   a. 첫 실행 온보딩(3단계 이내): 나이대, 가구원 수, 장애 여부, 대략 소득 구간, 시도. "이 정보는 휴대폰 안에만 저장됩니다" 명시. 건너뛰기 가능.
   b. 홈: "받을 수 있을지도 몰라요" 목록 — lib/calc 로 판정, 가능성 높음/확인 필요/해당 없음. 항목 탭 → 상세(이유, 신청 방법, 공식 링크, 웹 계산기 링크)
   c. 일정: calendar JSON 기반, 내 조건에 맞는 항목 위로. 항목별 알림 켜기/끄기
   d. 계산기: 웹과 같은 계산기 목록(중위소득, 기초연금, 장애인연금, 실업급여 등)
   e. 설정: 내 조건 수정·삭제, 알림 전체 끄기, 개인정보처리방침, 오픈소스 라이선스, "정부 기관과 무관 + 정보 출처" 안내
3. 데이터: 앱에 calendar JSON·기준 데이터를 번들로 포함하고, 온라인이면 https://bokjicard.co.kr/data/calendar-2027.json 을 받아 스키마 버전이 맞을 때만 교체.
4. 알림: 로컬 알림만(서버 푸시 없음). 시작 7일 전 오전 9시, 시작일, 마감 3일 전. Android 13+ 알림 권한은 "일정 탭에서 알림 켜기를 누를 때" 요청. 정확한 알람 권한은 쓰지 않는다(일반 예약으로 충분).
5. AdMob:
   - 배너: 홈·일정 화면 하단 적응형 배너 1개
   - 네이티브: 홈 목록 5개마다 1개(라벨 "광고")
   - 전면 광고 없음. 뒤로 가기·앱 실행 시 광고 없음.
   - 테스트 광고 단위 ID로 개발, 실제 ID는 빌드 환경변수로 주입
   - UMP(사용자 메시징 플랫폼) 동의 흐름 연결
6. 웹 환류: 상세 화면의 "자세히 보기"는 외부 브라우저(Custom Tabs)로 웹 페이지 열기 + utm_source=app.
7. 테스트: lib/calc 테스트 재사용 + 판정 로직 단위 테스트 + 알림 예약 날짜 계산 테스트(시간대 Asia/Seoul).
8. 빌드: targetSdkVersion 은 현재 Play 요구사항(2026-08-31 이후 API 36 이상으로 알려짐 — Play Console 공지로 재확인)에 맞춘다. 디버그 APK 빌드까지 실행하고 결과 보고. 릴리스 서명 키는 만들지 말고 운영자가 생성하는 절차를 문서로 남겨라(docs/app/release-signing.md).
9. docs/app/store-listing.md: 앱 이름 후보 3개, 짧은 설명(80자), 자세한 설명(정부 무관 고지·출처 URL 포함), 스크린샷 목록, 데이터 보안 섹션 답변 초안(기기 내 저장, AdMob 광고 ID 수집).
```
