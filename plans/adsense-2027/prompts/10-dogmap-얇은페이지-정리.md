# 프롬프트 10 — dogmap.co.kr 얇은 페이지 정리 (가장 먼저 실행)

## 왜 먼저인가
dogmap과 bokjicard는 같은 애드센스 계정을 쓴다. dogmap의 자동 생성 페이지 3,322개(목록 1,824 + 코스 1,443) 중 1곳짜리·공통 템플릿 위주 페이지가 "가치 없는 콘텐츠"나 대량 생성 콘텐츠로 판정되면 계정 전체가 영향을 받을 수 있다. 2026년 스팸 업데이트(3·6·8월)가 이 유형을 겨냥한 것으로 해석된다.

## 실행 저장소
dogmap 코드 저장소 (운영자가 알려 준 저장소)

## Claude Code에게
```
1. 페이지 재고 조사: sitemap.xml 의 모든 URL에 대해 빌드 결과(또는 데이터 소스)로 아래를 계산해 docs/audit/page-inventory.csv 로 저장하라.
   url, 유형(places/courses/guide/기타), 항목 수(장소 수 등), 본문 글자 수, 공통 템플릿을 뺀 고유 글자 수, 데이터 기준일
2. 분류 규칙:
   - KEEP: 항목 5개 이상 또는 고유 글자 수 800자 이상
   - MERGE: 같은 시군구의 업종 페이지 중 항목 1~4개 → 시군구 통합 페이지("○○구 애견동반 장소 전체")로 합치고 301
   - NOINDEX: 통합할 곳이 없는 1~2곳 페이지 → noindex,follow + 사이트맵 제외(사용자 이동 경로는 유지)
   - 코스 페이지: 거리·경사 외 고유 설명이 없으면 같은 길(예: 서해랑길)의 상위 페이지로 묶고 개별 구간은 noindex 검토
   분류 결과 개수를 먼저 보고하고, 운영자 승인 후에 실제로 적용하라.
3. 데이터 신선도: "2022-11-30 기준" 문구가 있는 데이터의 최신 공공데이터 버전이 있는지 확인(공공데이터포털 해당 데이터셋 페이지). 갱신 방법을 보고하고, 갱신 전까지 기준일을 명확히 표시.
4. 기술 결함(감사 결과): 한국어 404 페이지(현재 Next.js 기본 영문, title 깨짐, robots 메타 중복), 사이트 전체 og:image, rss 를 robots.txt 에 등록.
5. robots.txt: 사용자 대리 에이전트(ChatGPT-User, Claude-User, Perplexity-User)까지 막혀 있다. 학습용 크롤러만 막고 대리 에이전트는 허용하는 안을 만들어 운영자 결정을 받아라(Cloudflare 관리형 설정이면 대시보드 단계 안내).
6. 적용 후: 사이트맵 URL 수 변화, 301 맵(docs/audit/redirects.csv), noindex 목록을 보고.
```
